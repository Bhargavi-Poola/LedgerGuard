# LedgerGuard

Dynamic Multi-Tenant Zero-Knowledge Billing Engine

## Project Overview

LedgerGuard is a secure multi-tenant billing platform
designed to provide isolated company data,
reliable billing transactions and real-time analytics.

## Technology Stack

- React
- TypeScript
- Node.js
- Express.js
- MongoDB
- Redis
- JWT
- Socket.io
- Chart.js
